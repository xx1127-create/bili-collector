手动粘贴 Cookie（备用）
  1. 用 Chrome / Edge 打开 bilibili.com，确认已登录。
  2. 按 F12（Mac：⌥⌘I）打开开发者工具，切到「网络 / Network」，刷新页面。
  3. 点任意一个发往 bilibili.com 的请求，在「请求标头 / Request Headers」里找到 Cookie，复制整段值粘贴到上面。
