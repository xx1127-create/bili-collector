# B站视频采集器

一个在自己电脑上运行的小工具。用法很简单：你给出几个关键词，它去 B 站搜视频，再把搜到的 UP 主的全部视频都列出来，最后帮你挑出合适的频道，导出成 Excel。

> [!IMPORTANT]
> **第一次打开时，被 Mac 或 Windows 弹窗拦住了？**
> 从网上下载、没有做过「开发者签名」的程序，系统都会这样提醒一次。按 [这里的步骤](#blocked) 放行一次，以后双击就能直接打开。

## 一、下载

点本页面右上方绿色的 **Code** 按钮 → **Download ZIP**，下载后解压到任意文件夹。

（会用 git 的话，也可以运行 `git clone https://github.com/xx1127-create/bili-collector.git`）

## 二、打开

- **Windows**：双击 `启动.bat`
- **Mac**：双击 `启动.command`

被系统弹窗拦住的话，看下面的 [「第一次打开被拦住怎么办」](#blocked)。

第一次打开时，程序会自己安装需要的东西（Python 等），要联网，可能要等几分钟。以后再打开只要几秒。

装好后浏览器会自动打开页面。如果没打开，就自己在浏览器里输入 http://127.0.0.1:8765 。

**不用了就关掉那个黑色窗口**，程序就停了。

## 三、第一次打开被拦住怎么办

### Mac

**① 提示「无法验证开发者」，或「Apple 无法验证"启动.command"是否包含恶意软件」**

先看看自己的系统版本：点屏幕左上角的苹果图标 →「关于本机」。

- **macOS 14 及更早的版本**：在 `启动.command` 上点**右键**（或按住 Control 键再点）→ 选「打开」→ 弹窗里再点「打开」。
- **macOS 15 及以后的版本**（右键「打开」已经不管用了）：
  1. 在弹窗里点「完成」。
  2. 打开「系统设置」→「隐私与安全性」，往下滚到「安全性」那一栏。
  3. 那里会有一行说「启动.command」被阻止了，点旁边的「**仍要打开**」，输入开机密码。
  4. 再弹出窗口时，点「仍要打开」。

  没看到那一行的话，再双击一次 `启动.command`，然后回到「隐私与安全性」看。

**② 提示「没有权限」或「无法执行」**

打开「终端」（在「启动台」里搜「终端」），输入 `chmod +x`，后面加一个空格，然后把 `启动.command` 拖进终端窗口，按回车。之后再双击它。

**③ 弹窗问「"终端"想访问"下载"（或"桌面""文稿"）文件夹中的文件」**

点「**允许**」。程序要在自己的文件夹里保存数据。

**④ 弹出「安装命令行开发者工具」**

点「**安装**」。这是苹果官方的工具，里面带有程序需要的 Python。装好后，黑色窗口会自动接着往下走。

**上面都试了还是打不开**

打开「终端」，输入 `xattr -dr com.apple.quarantine`，后面加一个空格，然后把**整个程序文件夹**拖进终端窗口，按回车。这会去掉系统给这个文件夹打的「来自网上」的标记。之后再双击 `启动.command`。

### Windows

**① 蓝色窗口「Windows 已保护你的电脑」**

点窗口里的「**更多信息**」，再点「**仍要运行**」。

**② 「打开文件 - 安全警告」，说「无法验证发布者」**

点「**运行**」。

不想每次都弹的话：解压**之前**，在下载的 ZIP 文件上点右键 →「属性」→ 在最下面勾选「**解除锁定**」→「确定」，然后再解压。

**③ 「你要允许此应用对你的设备进行更改吗？」**

第一次安装 Python 时可能会弹，点「**是**」。

**④ 杀毒软件（比如 360、电脑管家）拦截了 `启动.bat`**

在杀毒软件的提示里选「允许」或「信任」，或者把程序文件夹加进信任列表。

**⑤ 防火墙提示「已阻止此应用的部分功能」**

点「允许」或「取消」都可以。程序只在你自己的电脑上运行，不影响使用。

## 四、使用

1. **先登录 B 站（建议）**：点右上角「扫码登录」，用 B 站手机 App 扫一下。不登录也能用，只是会被 B 站限速，非常慢。
2. **设置类别和关键词**：左边是类别列表，可以增加、修改、删除。每个类别里填上要搜的关键词。
3. **勾选要搜的类别**，点「**开始抓取**」，等它跑完。
   - 怕被 B 站限速的话，可以勾选「限时采集」，让它采一会儿、歇一会儿。
   - 中途停了也没关系，下次点「**继续上次采集**」，会从停下的地方接着采。
4. **看结果**：点页面顶部「查看结果」，可以按类别浏览搜到的视频和频道。
5. **挑频道**：点顶部「筛选」，程序会按规则自动把频道分成「入选」「筛掉」「待定」。你也可以手动改。
6. **导出**：在筛选页点「导出新入选频道」，生成的 Excel 在 `output` 文件夹里。

## 五、更新

- **一键更新**：每次打开页面，程序会自己查一下 GitHub。有新版本时，右上角会出现「有新版本，点这里更新」，点它再点「立即更新」，然后关掉黑色窗口、重新双击启动。只要能上 GitHub 就能更新，跟大家在不在同一个网络没关系。
- **连不上 GitHub 时**：请能上 GitHub 的人把程序 ZIP（Code → Download ZIP）发给你（比如用网盘、邮件或 U 盘）。在采集页最下面点「用 ZIP 文件更新」，选这个 ZIP 即可，不用解压。
- **从旧版本升级**（旧版本里没有更新按钮）：把新版本解压到旧版本旁边，关掉旧版本的黑色窗口，再双击新版本的启动。页面顶部会提示「发现旧版本」，点「把设置和数据搬过来」。

你建的类别、筛选规则、词库和抓到的数据都在 `data` 文件夹里，更新**不会**覆盖它们。每次修改前还会自动备份。

详见 [使用说明.md](使用说明.md) 的「更新程序」。

## 六、注意

- 你的设置、抓到的数据和登录信息都存在 `data` 文件夹里，只在你自己的电脑上，不会上传。
- **不要把 `data` 文件夹发给别人**，里面有你的 B 站登录信息。
- 换电脑时，想把以前的数据带过去，就把 `data` 文件夹复制到新电脑的同一位置。
- 出错时，把黑色窗口里的文字截图发给开发者。

更详细的说明（每个按钮、筛选规则、导出格式）见 [使用说明.md](使用说明.md)。
