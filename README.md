# B站视频采集器

一个在自己电脑上运行的小工具。用法很简单：你给出几个关键词，它去 B 站搜视频，再把搜到的 UP 主的全部视频都列出来，最后帮你挑出合适的频道，导出成 Excel。

## 一、下载

点本页面右上方绿色的 **Code** 按钮 → **Download ZIP**，下载后解压到任意文件夹。

（会用 git 的话，也可以运行 `git clone https://github.com/xx1127-create/bili-collector.git`）

## 二、打开

- **Windows**：双击 `启动.bat`
- **Mac**：双击 `启动.command`
  - 如果提示「无法验证开发者」：右键点它 →「打开」→「打开」，以后就能直接双击了。

第一次打开时，程序会自己安装需要的东西（Python 等），要联网，可能要等几分钟。以后再打开只要几秒。

装好后浏览器会自动打开页面。如果没打开，就自己在浏览器里输入 http://127.0.0.1:8765 。

**不用了就关掉那个黑色窗口**，程序就停了。

## 三、使用

1. **先登录 B 站（建议）**：点右上角「扫码登录」，用 B 站手机 App 扫一下。不登录也能用，只是会被 B 站限速，非常慢。
2. **设置类别和关键词**：左边是类别列表，可以增加、修改、删除。每个类别里填上要搜的关键词。
3. **勾选要搜的类别**，点「**开始抓取**」，等它跑完。
   - 怕被 B 站限速的话，可以勾选「限时采集」，让它采一会儿、歇一会儿。
   - 中途停了也没关系，下次点「**继续上次采集**」，会从停下的地方接着采。
4. **看结果**：点页面顶部「查看结果」，可以按类别浏览搜到的视频和频道。
5. **挑频道**：点顶部「筛选」，程序会按规则自动把频道分成「入选」「筛掉」「待定」。你也可以手动改。
6. **导出**：在筛选页点「导出新入选频道」，生成的 Excel 在 `output` 文件夹里。

## 四、注意

- 抓到的数据和登录信息都存在 `data` 文件夹里，只在你自己的电脑上，不会上传。
- **不要把 `data` 文件夹发给别人**，里面有你的 B 站登录信息。
- 换电脑时，想把以前的数据带过去，就把 `data` 文件夹复制到新电脑的同一位置。
- 出错时，把黑色窗口里的文字截图发给开发者。

更详细的说明（每个按钮、筛选规则、导出格式）见 [使用说明.md](使用说明.md)。
